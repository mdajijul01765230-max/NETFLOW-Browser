## ১. উদ্দেশ্য ও প্রমাণের স্তর (Purpose & Evidence Levels)

* **বাংলা:** NETFLOW Browser V2 একটি ফুল-ফিচারড স্ট্যান্ডঅ্যালোন ব্রাউজার ইঞ্জিন নয়; এটি Android-এর বিল্ট-ইন **Android System WebView (`android.webkit.WebView`)** এবং একটি লো-ব্যান্ডউইথ প্রক্সি ব্যাকএন্ড (`server.ts`)-এর ওপর নির্মিত একটি হাইব্রিড ব্রাউজার। নিচে স্পষ্টভাবে উল্লেখ করা হলো **Google Chrome (Android)**-এ কী কী সুবিধা রয়েছে যা NETFLOW-তে নেই অথবা আংশিকভাবে রয়েছে, কেন তা নেই এবং প্রতিটি দাবির প্রমাণের স্তর (`VERIFIED`, `INFERRED`, অথবা `NOT VERIFIED`) কী।
* **English:** NETFLOW Browser V2 is not an independent Chromium fork; it is a Capacitor + React shell hosting Android's **`android.webkit.WebView`** alongside an Express transformation proxy (`server.ts`). This document enumerates what **Google Chrome for Android** provides that NETFLOW either lacks completely or supports only partially, the technical reason for each gap, and the exact evidence level (`VERIFIED`, `INFERRED`, or `NOT VERIFIED`).
